# Avalon

### حاسوب واحد بنظام Windows 10/11 x64. عدة أسطح مكتب مستقلة.

يحوّل Avalon مضيف Windows 10/11 x64 واحداً إلى عدة مثيلات سطح مكتب يمكن الوصول إليها بشكل مستقل. ويمكن لكل مثيل امتلاك جلسة Windows وشاشة افتراضية وإدخال وصوت وتطبيقات وألعاب واتصال Moonlight خاص به.

## ما هو Avalon؟

Avalon منصة لبث سطح المكتب متعدد الجلسات على Windows 10/11 x64. بدلاً من تخصيص الحاسوب بالكامل لسطح مكتب تفاعلي واحد، يسمح بتشغيل عدة مثيلات Windows مستقلة على المضيف نفسه من دون الحاجة إلى آلة افتراضية كاملة لكل مستخدم.

---

## القدرات الأساسية

- عدة مثيلات Windows مستقلة على مضيف واحد
- سياق بث مستقل لكل مثيل
- شاشة افتراضية ودقة ومعدل تحديث لكل مثيل
- مسارات مستقلة للوحة المفاتيح والفأرة وصوت الجلسة
- يحافظ Avalon على دورة حياة الجلسة من دون إبقاء عميل RDP خارجي متصلاً
- الإنشاء والاقتران والحالة والتشخيص عبر الويب
- يبقى Moonlight هو العميل على الهواتف والأجهزة اللوحية وأجهزة التلفاز والحواسيب

---

## كيف يعمل؟

أنشئ مثيلاً، واختر إعدادات العرض ثم قم بإقران العميل. يجهّز Avalon جلسة Windows والشاشة الافتراضية وسياق البث ودورة الحياة، وبعدها تتصل عبر Moonlight.

```text
Windows 10/11 x64 Host
        │
      Avalon
        │
 ┌──────┼──────┐
 ▼      ▼      ▼
Instance 01  Instance 02  Instance 03
 │      │      │
 ▼      ▼      ▼
Moonlight  Moonlight  Moonlight
```

---

## مصمم للعمل مع Moonlight

يغيّر Avalon جانب المضيف بدلاً من استبدال العميل الذي تعرفه. ويمكن الاستمرار باستخدام Moonlight على Windows وLinux وmacOS وAndroid وiOS/iPadOS وAndroid TV وغيرها من الأجهزة المدعومة.

---

## حالات استخدام شائعة

- الألعاب المنزلية: أشخاص مختلفون يستخدمون مثيلات مختلفة في الوقت نفسه
- حسابات متعددة وأحمال عمل متعددة المثيلات
- عدة محطات عمل بعيدة على حاسوب قوي واحد
- الاختبار والأتمتة وبيئات التوافق
- Homelab والحوسبة البعيدة ذاتية الاستضافة

---

## نموذج العزل

يوفر Avalon عزلاً على مستوى جلسة Windows وليس عزلاً كاملاً لآلة افتراضية. تكون أسطح المكتب والتطبيقات والشاشات والإدخال والصوت منفصلة بين المثيلات، بينما تتم مشاركة Windows والنواة وCPU وGPU والعتاد الفعلي للمضيف. لذلك لا ينبغي اعتباره حداً أمنياً بمستوى VM.

---

## المنصة والأداء

يستهدف Avalon إصدارات Windows 10 وWindows 11 ذات 64 بت. وتعتمد الدقة ومعدل التحديث وبرامج الترميز وHDR وعدد المثيلات المتزامنة على GPU وبرامج التشغيل والمشفّر والشبكة وعتاد العميل.

---

## حالة المشروع

Avalon حالياً في مرحلة Alpha. ما تزال الواجهة والتوافق والمكونات منخفضة المستوى تتطور، لذلك قد تحدث تغييرات غير متوافقة وحالات خاصة مرتبطة بالأجهزة.
