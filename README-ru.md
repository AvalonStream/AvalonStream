# Avalon

### Один ПК с Windows 10/11 x64. Несколько независимых рабочих столов.

Avalon превращает один хост Windows 10/11 x64 в несколько независимо доступных настольных экземпляров. Каждый экземпляр может иметь собственный сеанс Windows, виртуальный дисплей, ввод, звук, приложения, игры и подключение Moonlight.

**Один хост. Несколько экземпляров.**

## Что такое Avalon?

Avalon — платформа многосеансового стриминга рабочего стола для Windows 10/11 x64. Вместо того чтобы отдавать весь ПК одному интерактивному рабочему столу, она позволяет нескольким независимым экземплярам Windows работать на одном хосте без отдельной полноценной виртуальной машины для каждого пользователя.

---

## Основные возможности

- Несколько независимых экземпляров Windows на одном хосте
- Отдельный контекст стриминга для каждого экземпляра
- Виртуальный дисплей, разрешение и частота обновления для каждого экземпляра
- Независимые пути клавиатуры, мыши и аудио сеанса
- Avalon поддерживает жизненный цикл сеанса без постоянного внешнего RDP-клиента
- Создание, сопряжение, состояние и диагностика через Web
- Moonlight остаётся клиентом на телефонах, планшетах, ТВ и ПК

---

## Как это работает

Создайте экземпляр, выберите параметры дисплея и выполните сопряжение клиента. Avalon подготовит сеанс Windows, виртуальный дисплей, контекст стриминга и жизненный цикл; затем подключайтесь через Moonlight.

```text
Windows 10/11 x64 Host
        │
      Avalon
        │
 ┌──────┼──────┐
 ▼      ▼      ▼
Instance 01  Instance 02  Instance 03
 │      │      │
 ▼      ▼      ▼
Moonlight  Moonlight  Moonlight
```

---

## Создано для Moonlight

Avalon меняет сторону хоста, а не привычный клиент. Moonlight продолжает работать на Windows, Linux, macOS, Android, iOS/iPadOS, Android TV и других поддерживаемых устройствах.

## Типичные сценарии

- Домашние игры: разные пользователи одновременно работают в разных экземплярах
- Несколько аккаунтов и многократный запуск
- Несколько удалённых рабочих мест на одном мощном ПК
- Тестирование, автоматизация и среды совместимости
- Homelab и самостоятельный хостинг удалённых вычислений

---

## Модель изоляции

Avalon обеспечивает изоляцию на уровне сеансов Windows, а не полную изоляцию виртуальной машины. Рабочие столы, приложения, дисплеи, ввод и аудио разделены, но хостовая Windows, ядро, CPU, GPU и физическое оборудование общие. Avalon не следует считать границей безопасности уровня VM.

---

## Платформа и производительность

Avalon ориентирован на 64-разрядные Windows 10 и Windows 11. Разрешение, частота обновления, кодеки, HDR и количество одновременных экземпляров зависят от GPU, драйверов, кодировщика, сети и клиентского оборудования.

---

## Статус проекта

Avalon сейчас находится на стадии Alpha. Интерфейс, совместимость и низкоуровневые компоненты продолжают меняться, поэтому возможны несовместимые изменения и аппаратно-зависимые крайние случаи.
